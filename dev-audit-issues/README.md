# Dev — Audit et issues

Deux skills réutilisables : `audit-express` pour auditer un projet en lecture seule et `create-issues` pour préparer des brouillons d'issues GitHub en français, sans publication automatique.

## Installation dans Codex

Dans un terminal, enregistrer le catalogue du cours puis installer le plugin :

```powershell
codex plugin marketplace add "C:\dev\Perso\Learn\dymacourse\dyma-claude"
codex plugin add dev-audit-issues@dyma-claude-cours
```

Les sources restent dans le dossier du cours : inutile de copier le plugin dans chaque projet. Garder ce dossier accessible.

Ouvrir ensuite le projet à auditer dans Codex, démarrer un nouveau chat et sélectionner **Dev — Audit et issues**.

## Utilisation

> Utilise audit-express du plugin dev-audit-issues pour auditer ce projet en lecture seule.

> Utilise create-issues du plugin dev-audit-issues pour préparer une issue à partir du constat A1.
