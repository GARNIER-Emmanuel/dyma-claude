
# Checklist de qualité

## Angular / TypeScript
- Les composants sont-ils simples à comprendre ?
- La logique métier est-elle séparée de l'affichage ?
- Le typage TypeScript est-il correctement utilisé ?

## Général
- Y a-t-il du code dupliqué ?
- Les noms sont-ils compréhensibles ?
- Y a-t-il des tests ?
